# Basic POS System

This is a four-page CodeIgniter 4 website using static PHP arrays.

## Pages

- `/`
- `/about`
- `/customers`
- `/users`

## Run with XAMPP

1. Place the `fa2` folder in `C:\xampp\htdocs`.
2. Start Apache in XAMPP.
3. Open `http://localhost/fa2/public/`.

PHP 8.2 or newer is required.

Database was added in this activity.
